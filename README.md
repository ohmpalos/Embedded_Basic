# Embedded Basic Firmware

Arduino 기반 임베디드 시스템 기초 실습 예제 소스코드부터 임베디드 기능사 실전 문제까지 소스코드입니다.

## 예제 목록

### 01. RGB LED Sequence
RGB LED의 색상을 순차적으로 제어하는 예제입니다.

- 폴더: `01_RgbLedSequence`
- 소스파일: `01_RgbLedSequence.ino`

### 02. Button
버튼 입력을 이용한 디지털 입력 실습 예제입니다.

## 사용 환경

- Arduino IDE
- Arduino UNO
- C/C++ 기반 Arduino Sketch

## 교재 연계

본 저장소는 임베디드 시스템 관련 실습 교재의 예제 소스코드를 제공합니다.
교재의 QR코드를 스마트폰으로 스캔하면 해당 예제의 최신 소스코드에 접근할 수 있습니다.
